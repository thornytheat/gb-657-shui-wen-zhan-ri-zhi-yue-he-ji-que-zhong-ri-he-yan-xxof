# hydrocalendar 水文站日值月合计缺重日核验

流域数据员导入多站日值，系统区分零雨与缺测，按数据版本裁决重复日，用 Decimal 计算月合计并标出不完整月份。

## 模块

- 日值采信：单位、空值、编码与坏行隔离。
- 站点日历：启停日期、闰日和当地自然日。
- 缺重日判定：零雨、缺测、重复版本与冲突。
- 月量计算：日值汇总、覆盖率与月报状态。
- 跨站复核：相邻站差异与复核证据。
- 批次对账：输入、采纳、重复、隔离四账；规范版本绑定与升级。
- 月报导出：单一 CSV 与运行证据。

## 规范版本

现行规范 `hydrocalendar/2.0.0` 要求逐行明示单位；`hydrocalendar/1.0.0` 允许按契约补齐。规范版本写进批次，旧账不随现行契约改动：升级入口原地迁移、可续跑，证据不足时明确拒绝。详见 `docs/DATA-DICTIONARY.md` §10。

## 启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:18216/>。

## 测试

```bash
docker compose exec -T app pytest -q
```

核心反例包括：零雨误作缺测、后写低版本覆盖高版本、闰年二月缺日、单位混用和同版本不同值。
